🏫 What is an FLN Base Line Test?

The Foundational Literacy and Numeracy (FLN) Base Line Test helps schools understand the existing learning levels of students in foundational literacy and numeracy.

📊 Purpose of the School Report

The school report provides a record of Base Line Test results and can support academic planning, classroom activities and monitoring of foundational learning.

👩‍🏫 Useful for Teachers and Schools

Teachers and school staff can use these reports for academic planning, reference, monitoring learning progress and maintaining school-level records.

📱 Easy Access

Reports can be searched from a mobile phone, tablet, laptop or desktop computer. No separate application is required.

Please enter the correct School Name or UDISE Code. The report opens directly from the corresponding school report file.

🔐 Privacy and Responsible Use

These reports should be used only for legitimate educational, academic and administrative purposes. Please handle student-related information responsibly.
